# Yuhina brand

- `yuhina-mark.svg` — in-app mark, uses `currentColor`, transparent background.
- `yuhina-icon.svg` — 1024×1024 app icon source, transparent background, neutral
  light mark for dark taskbars/docks.

The mark is a single geometric Y: two swept wings meeting at the center and a
tapered stem. Keep it monochrome; do not add a background, gradient, or game
texture.

Generate platform icons from `yuhina-icon.svg` with `npm run icons`.
